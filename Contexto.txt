1. OBJETIVO DEL TRABAJO REALIZADO:
----------------------------------
Migración completa de la maqueta prototipo original (páginas estáticas en HTML5, 
CSS3 y lógica en vanilla JS) a una Aplicación de Página Única (SPA) moderna 
construida con React y empaquetada con Vite, manteniendo al 100% el diseño visual,
las imágenes originales y las reglas de negocio/validación solicitadas en la pauta.


2. ESTADO INICIAL VS. ESTADO FINAL:
-----------------------------------
- Estado Inicial:
  * Existían archivos HTML independientes (index.html, productos.html, carrito.html, etc.).
  * Se habían instalado dependencias en package.json pero faltaba la configuración de Vite.
  * 'src/main.jsx' estaba en 0 bytes (React nunca se montaba).
  * 'index.html' no tenía el <div id="root"></div> ni el script hacia main.jsx.
  * package.json no tenía scripts de inicio ("dev", "build") y usaba "commonjs".
  * 'node_modules' se había subido por error al repositorio sin un '.gitignore'.
  * Las carpetas 'src/components' y 'src/pages' estaban vacías.

- Estado Final:
  * Proyecto 100% operativo en React 19 + Vite.
  * Enrutamiento dinámico mediante React Router DOM.
  * Estado global del carrito mediante React Context API con persistencia en localStorage.
  * Todos los formularios con validaciones en tiempo real (según la pauta de Duoc UC).
  * Repositorio optimizado: '.gitignore' agregado y 'node_modules' removido del seguimiento de Git.
  * Compilación validada sin errores ('npm run build' exitoso).

4. CUMPLIMIENTO DE REQUERIMIENTOS FUNCIONALES (PAUTA / ERS):
------------------------------------------------------------
- RF1: Registro de Usuario ('Registro.jsx'):
  * Validación de nombre obligatorio.
  * Formato válido de correo electrónico y confirmación obligatoria coincidente.
  * Contraseña mínima de 6 caracteres y confirmación coincidente.
  * Selección obligatoria de Región y Comuna según pauta chilena.
  * Redirección a Login tras registro exitoso.

- RF2: Inicio de Sesión ('Login.jsx'):
  * Campos controlados para correo y contraseña con feedback al usuario.

- RF3: Navegación del Sitio ('Header.jsx' y 'App.jsx'):
  * Enlaces SPA sin recargar la página: Home, Productos, Nosotros, Blogs, Contacto y Carrito.
  * El enlace activo se destaca visualmente gracias a NavLink y la clase '.active-link'.

- RF4: Listado de Productos ('Productos.jsx' y 'ProductCard.jsx'):
  * Despliegue de tarjetas con imagen, nombre, categoría y precio en formato chileno ($24.990).
  * Botón directo hacia el detalle del producto.

- RF5: Detalle de Producto ('DetalleProducto.jsx'):
  * Ruta dinámica '/productos/:id'.
  * Muestra imagen amplia, categoría, descripción detallada y precio.
  * Input numérico para elegir cantidad (1 a 99) y botón "Añadir al carrito" con aviso visual.

- RF6 y RF7: Carrito de Compras y Persistencia ('CartContext.jsx' y 'Carrito.jsx'):
  * Conservación automática del carrito en el navegador usando 'localStorage'.
  * Modificación de cantidad de productos en tiempo real con recálculo de subtotales y total general.
  * Eliminación de ítems del carrito.
  * Contador global de productos reflejado inmediatamente en el Header: "🛒 Carrito (N)".
  * Vista de estado vacío con botón para volver a la tienda.

- RF8: Formulario de Contacto ('Contacto.jsx'):
  * Nombre requerido con límite de 100 caracteres.
  * Correo requerido con validación de dominios permitidos: @duoc.cl, @profesor.duoc.cl, @gmail.com.
  * Mensaje requerido con límite de 500 caracteres.
  * Limpieza del formulario y mensaje de confirmación tras el envío.


5. INSTRUCCIONES PARA EJECUTAR EN CUALQUIER COMPUTADORA:
---------------------------------------------------------
1. Requisitos:
   - Tener instalado Node.js (versión 18 o superior recomendada).
   - Tener Git instalado (si se clona desde GitHub).

2. Pasos de instalación y ejecución:
   a) Abrir una terminal en la carpeta raíz del proyecto ('nutrivida').
   b) Instalar las dependencias del proyecto:
      npm install

   c) Iniciar el servidor de desarrollo en modo local:
      npm run dev

   d) Abrir el navegador en la URL indicada por la consola:
      http://localhost:5173/

3. Generar compilación para producción (Build):
   npm run build

4. Probar la versión de producción localmente:
   npm run preview

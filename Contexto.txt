4. SERVICIO DE DATOS SIMULADO ('dataService.js'):
-------------------------------------------------
Cumpliendo el requisito del "Archivo de datos en JavaScript", 'src/services/dataService.js' 
provee una API completa en JavaScript con persistencia en localStorage:

- CRUD de Productos:
  * getProducts(), getProductById(id), getProductsByCategory(catId), getProductsInOffer()
  * getCriticalStockProducts(): detecta productos con stock <= stockCritico (alerta administrativa)
  * createProduct(data), updateProduct(id, data), deleteProduct(id)

- CRUD de Categorías:
  * getCategories(), getCategoryById(id)
  * createCategory(data), updateCategory(id, data), deleteCategory(id)

- CRUD de Usuarios y Sesión:
  * getUsers(), getUserById(id)
  * createUser(data), updateUser(id, data), deleteUser(id)
  * login(email, password), logout(), getCurrentUser()

- Gestión de Órdenes (Checkout):
  * createOrder(orderData): genera ID único, fecha, detalle de productos, resta stock automáticamente.
  * getOrders(), getOrderById(id), getOrdersByUser(userId)

6. INSTRUCCIONES PARA EJECUTAR EN CUALQUIER COMPUTADORA:
---------------------------------------------------------
1. Requisitos previos:
   - Node.js versión 18 o superior instalado.
   - Navegador web moderno (Chrome, Edge, Firefox, Safari).

2. Instalación de paquetes:
   Abrir terminal en la carpeta 'nutrivida':
   
   npm install

   * NOTA IMPORTANTE (en redes corporativas o de Duoc con proxy SSL):
     Si npm muestra el error 'UNABLE_TO_VERIFY_LEAF_SIGNATURE', ejecutar:
     npm install --strict-ssl=false

3. Iniciar el servidor de desarrollo:
   npm run dev

   Abrir la URL que aparece en la consola (habitualmente http://localhost:5173/).

4. Compilar para producción (Build):
   npm run build

   (Genera la carpeta 'dist/' optimizada, verificada sin advertencias ni errores).

5. Previsualizar la versión de producción:
   npm run preview
